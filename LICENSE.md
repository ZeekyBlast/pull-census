# Licences

Pull Census uses a different licence for each part of the repo.

| Part | Licence | Full text |
| --- | --- | --- |
| `packages/*` (the maths, parsers and tests) | MIT | [`packages/core/LICENSE`](packages/core/LICENSE) |
| `apps/*` (the API, and later the site and bot) | AGPL-3.0-only | <https://www.gnu.org/licenses/agpl-3.0.txt>, with a copy in each app |
| Published dataset releases | CC BY 4.0 | <https://creativecommons.org/licenses/by/4.0/> |
| Everything else (`rules/`, `methods/`, `scripts/`, `docs/`, root config) | MIT | [`packages/core/LICENSE`](packages/core/LICENSE) |

Third-party files (vendored dictionaries, fonts) keep their own licences, stored beside them.

The OneBST dataset used for calibration has no licence. It is never committed or published.
